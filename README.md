# 🛒 E-Commerce Website – WordPress & WooCommerce

## 📌 Overview

This project is a complete e-commerce website developed using **WordPress** and **WooCommerce**, dedicated to the sale of electronic products.

The website provides customers with a simple and user-friendly shopping experience, while allowing the administrator to manage products, categories, prices, inventory, and product variations.

---

## 🎯 Project Objective

The main objective of this project is to design and develop a functional online store using WordPress and WooCommerce.

The project focuses on:

- Creating an online product catalog
- Organizing products into categories
- Managing product variations
- Managing prices and inventory
- Providing detailed product information
- Improving the customer shopping experience
- Managing the website through the WordPress administration dashboard
